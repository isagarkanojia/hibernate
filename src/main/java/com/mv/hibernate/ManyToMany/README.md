# Many-to-Many Relationship Example

This package demonstrates **Many-to-Many relationships** in Java using **JPA/Hibernate**.

## 📚 Scenario

**Many Customers can have Many Products**

- **Customer** (MANY side) - Can subscribe to multiple products
- **Product** (MANY side) - Can belong to multiple customers
- **Junction Table**: `customer_product` - Links customers and products
- Relationship: Customer ↔ customer_product ↔ Product

## 🔑 Key Concept

Unlike One-to-Many or Many-to-One, **Many-to-Many requires a junction table** to store the relationships between two entities.

## 📁 Files Created

### 1. Entities

#### `Product.java` (in model package)
- Represents banking products (Savings Account, Credit Card, Insurance, etc.)
- Simple entity, no relationship annotation on this side

#### `CustomerWithProducts.java` (in model package)
- Customer entity with **@ManyToMany** relationship to Products
- Uses `@JoinTable` to specify the junction table

```java
@ManyToMany(fetch = FetchType.EAGER)
@JoinTable(
    name = "customer_product",           // Junction table name
    joinColumns = @JoinColumn(name = "customer_id"),        // FK to customer
    inverseJoinColumns = @JoinColumn(name = "product_id")  // FK to product
)
private List<Product> products;
```

### 2. Repository

#### `CustomerWithProductsRepository.java`
- Spring Data JPA repository
- Method: `findByPan(String pan)`

### 3. Service

#### `ManyToManyJPAExample.java` ⭐
**One Simple Method:**
- `getCustomerWithProducts(Long customerId)` - Get customer with all their products

## 🔍 Database Structure

### Tables

```sql
-- Customer table
CREATE TABLE customer (
    id BIGINT PRIMARY KEY,
    name VARCHAR(100),
    pan VARCHAR(20),
    dob DATE,
    risk_score INT
);

-- Product table
CREATE TABLE product (
    id BIGINT PRIMARY KEY,
    name VARCHAR(100),
    type VARCHAR(50),
    description TEXT,
    base_charges DECIMAL(10,2)
);

-- Junction table (the key to Many-to-Many!)
CREATE TABLE customer_product (
    customer_id BIGINT NOT NULL,
    product_id BIGINT NOT NULL,
    subscribed_date DATE,
    status VARCHAR(30),
    PRIMARY KEY (customer_id, product_id),
    FOREIGN KEY (customer_id) REFERENCES customer(id),
    FOREIGN KEY (product_id) REFERENCES product(id)
);
```

## 🎓 Key Learning Points

### What Makes it Many-to-Many?

1. **No foreign key in either main table**
2. **Junction table has composite primary key** (customer_id, product_id)
3. **Both entities can have multiple related records**

### SQL Generated by Hibernate

```sql
-- Fetches customer
SELECT * FROM customer WHERE id = 1;

-- Fetches products through junction table
SELECT p.* 
FROM product p
INNER JOIN customer_product cp ON p.id = cp.product_id
WHERE cp.customer_id = 1;
```

### Comparison with Other Relationships

| Relationship | Foreign Key Location | Junction Table? |
|--------------|---------------------|-----------------|
| **One-to-Many** | Child table | ❌ No |
| **Many-to-One** | Child table | ❌ No |
| **Many-to-Many** | Junction table | ✅ **YES** |

## 📝 JPA Annotations

```java
@ManyToMany              // Defines the relationship
@JoinTable(              // Specifies junction table details
    name = "...",        // Junction table name
    joinColumns = ...,   // FK to THIS entity
    inverseJoinColumns = ... // FK to OTHER entity
)
```
